# Калькулятор эффекта инициатив

Оценка инициатив банка/финтеха: инкрементальный эффект, ROMI, P&L, NPV, окупаемость,
охват и RICE — с вердиктом GO / GO-с-контролем / NO-GO.

Считает четыре типа инициатив: коммуникация по своей базе, рекламная кампания ФРК 1–4,
вывод продукта на полку, пилот или акция.

**Первый раз? Начните с [docs/КАК_ПОЛЬЗОВАТЬСЯ.md](docs/КАК_ПОЛЬЗОВАТЬСЯ.md)** — объяснение
на пятнадцать минут: зачем это, как пройти путь, как читать результат и чего модель не умеет.

## Быстрый старт

```bash
git init && git add -A && git commit -m "Калькулятор эффекта инициатив — стартовая версия"
claude
```

Дальше в Claude Code достаточно описать инициативу словами — навык из `.claude/skills/`
подхватится сам, задаст недостающие вопросы и посчитает.

Или напрямую:

```bash
make test                                    # 30 стресс-тестов движка
make calc CASE=cases/frk1_debit_card.json    # расчёт кейса
make xlsx                                    # пересобрать Excel-модель
```

Зависимости: Python 3.10+, `openpyxl` (только для Excel). LibreOffice — для пересчёта Excel.

## Что внутри

| | |
|---|---|
| `src/calc.py` | Движок. Единственный источник истины по формулам. |
| `src/build_xlsx.py` | Генератор Excel-зеркала модели. |
| `docs/*.xlsx` | Excel с живыми формулами: листы Ввод / Каналы / Модель / P&L / Итог / Методика. |
| `cases/*.json` | Реальные кейсы, они же примеры формата конфига. |
| `tests/stress_test.py` | Инварианты, крайние случаи, монотонность. |
| `.claude/skills/` | Навык для диалогового режима в Claude Code. |
| `CLAUDE.md` | Контекст проекта: принципы, формулы, найденные ловушки. |
| `BACKLOG.md` | Что не доделано и в каком порядке брать. |

## Два режима работы

**Диалоговый (навык).** Описываете инициативу — Claude классифицирует тип, задаёт минимум
вопросов, добирает недостающее бенчмарками или веб-поиском, считает и выдаёт отчёт с вердиктом.
Подходит, когда нужен быстрый ответ и часть данных неизвестна.

**Ручной (Excel).** Открываете `docs/Калькулятор_эффекта_инициатив.xlsx`, меняете синие ячейки.
Лист «Методика» объясняет каждую формулу и границы её применимости. Подходит, когда хотите
покрутить допущения сами или отдать модель коллегам без Claude.

Обе версии считают одно и то же и сверены до рубля.

## Кейсы в комплекте

| Файл | Что это | Вердикт |
|---|---|---|
| `frk1_debit_card.json` | ФРК 1 на дебетовую карту, 180 млн ₽ | NO-GO, оптимум ФРК 4 |
| `comms_push_base.json` | Push-кампания по базе | GO |
| `product_launch_credit_card.json` | Новая кредитка на полку, IT 120 млн ₽ | NO-GO |
| `referral_youth_deposit.json` | Реферальная программа, 500 бонусов обоим | NO-GO по экономике юнита |

## Формат конфига

Смотрите любой файл в `cases/`. Ключевые поля:

- `meta` — горизонт, ставка дисконтирования
- `audience` — размер ЦА, органический поток заявок, halo-период
- `channels[]` — тип (`internal` / `perform` / `brand`), `frk_tier` для лестницы, бюджет, CPM, конверсии
- `funnel` — approval, activation, каннибализация, deadweight
- `unit_economics` — баланс, NIM, оборот, интерчейндж, кэшбэк, CoR, ramp-up, отток
- `costs` — производство, IT, opex и **`acq_cost_per_client`** (переменная выплата за привлечение)
- `confidence` — сколько допущений каждого грейда (A/B/C/D)

## Что модель намеренно не даёт сделать

- Выдать одну цифру вместо трёх сценариев.
- Сказать «GO» при слабых данных: индекс уверенности ниже 0,6 переводит вердикт в «сначала пилот».
- Списать весь эффект на перформанс: brand-часть считается отдельно и помечается как
  недоказанная без geo-holdout или MMM.
- Поставить каннибализацию в ноль без обоснования.
- Посчитать кредитный продукт без Cost of Risk.

## Границы применимости

Модель линейна по бюджету — насыщения канала нет, есть только предупреждение о нём.
Пересечение аудиторий считается по формуле независимости. Отток плоский. Сезонности
и конкурентной реакции нет. Подробно — лист «Методика» в Excel и `CLAUDE.md`.
